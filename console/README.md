# 启动器与控制台

[文档目录](../docs/README.md) · [首次安装](../docs/first-start.md)

## 打开与管理服务

完成首次安装后，双击根目录的 `start-console.cmd`。界面在 Microsoft Edge 独立窗口中运行。点击顶部“启动服务”，就绪后显示工作台；游戏由工作台中的“启动游戏”按钮打开。

游戏服务默认连接 `http://127.0.0.1:18083`。启动器使用独立本机端口，服务关闭时仍可操作。顶部提供启动、停止、重启，底部可展开最近日志。关闭窗口不会结束后台服务，再次打开复用同一启动器。

PowerShell 手动启动的进程显示为“外部服务”，可以连接，但不能直接管理。先在原窗口按 Ctrl+C 停止一次，再从启动器启动即可。停止、重启会等待当前请求结束，并中断游戏连接，操作前请完成当前游戏动作。

需要指定地址或数据目录时，在项目根目录运行：

```powershell
.\start-console.ps1 -Port 18083 -DataDirectory '.\data-pc-1.15.0'
```

连接参数保存到 `%LOCALAPPDATA%\DotAbyssConsole\settings.json`，下次沿用。服务已启动但控制台仍连接旧环境时，先检查这里的目录和端口。

## 存档与游戏启动

1. 顶部选择或新建存档。新档走教程，可分别填写存档名称与游戏昵称。
2. 点击“启动游戏”。首次自动创建 `pc-local.json`，写入已验证的隔离目录、本机地址和所选存档标识。
3. 需要切换游戏存档时，先退出游戏，再选择另一份存档启动。

顶部区分“当前编辑档”与“游戏使用档”。打开窗口时优先选择运行中的游戏档，其次恢复上次选择；手动切换后不会被心跳自动改回。另一个档案在线不代表当前编辑档在线。

重命名只改变控制台显示名称，不改变内部登录标识、游戏昵称或进度。显示名称支持中文，最多 64 个可见字符，并检查重名；游戏昵称通过“玩家资料”修改。

启动前校验客户端版本、主数据、资源映射及插件。已存在的配置会备份，启动失败时恢复；首次创建失败则恢复为不存在。运行中不会再开第二份游戏，也不会自动终止游戏切换存档。

## 编辑与热更新

1. 在左侧选择功能，从“可用操作”选择修改项。
2. 填写参数，可用“选择…”按名称或 ID 查找并多选。
3. 点击“预览修改”，核对范围、数量、提示和生效方式。
4. 点击“应用修改”，查看底部同步状态。

“存档数据”只读，用于核对字段；“内容目录”显示当前主表。“本地规则”和“主数据”各有预览流程，未开放编辑的字段保持只读。修改表单、切换存档或发现数据已变化，会使旧预览失效。

热更新方式因功能而异：有的可实时同步，有的需要切换页面、下一场战斗或重新登录。加成结算、进行中的深渊快照与更新限制见[养成、奖励与解锁](../docs/progression-and-rewards.md)。

“任务与邮件”支持分别开放特殊任务天数、批量设置任务完成状态、领取所选或本组可领任务奖励。选择类别与分组后可指定任务或全选；完成不会直接发奖，已领奖励不会重复发放。下一周期仍按正常进度开始，操作范围和示例见[任务批量操作](../docs/progression-and-rewards.md#任务批量操作)。

角色、装备、技能、卡池、商品、剧情和奖励显示关联名称并保留 ID；已有翻译缓存时优先显示译名，支持按译名、原文和 ID 搜索。名称只用于展示，提交与导出仍使用原始数据；没有可靠关联的编号保留原值。窄表格可横向滚动，点击行可查看完整字段。

## 备份与恢复

“存档备份”支持手动备份、JSON 导入导出，以及预览恢复到某次操作之前。打开文件不会直接覆盖存档，恢复仍需预览并应用。回退到旧版代码时，应使用与该版本兼容的存档备份，不能只替换程序文件。

## 翻译与备用入口

“繁体中文”栏可一键安装或更新，并展开进度、日志。先退出游戏；安装任务独立于游戏服务，完成后重开游戏生效。来源、依赖及覆盖范围见[翻译集成说明](../pc-translation/README.md)。

- F5 刷新当前页，Ctrl+F 聚焦搜索；会话失效后重新打开启动器。
- `start-console.ps1 -Demo` 或 `-NoConnect` 打开隔离演示，不连接真实服务。
- `start-console.ps1 -Classic` 使用备用 Tk 界面。

## 开发约束

启动 API 只接受 `profile_id`，不接受任意程序路径。操作系统锁避免重复启动，进程 ID、创建时间与有效心跳共同识别运行档案。服务管理使用固定 Python、数据目录和模块，外部进程只连接、不冒充托管进程。

控制器仅供本机访问，检查 Host、Origin 和会话。管理凭据来自数据目录的 `admin-token.txt`，通过一次性票据建立网页会话，不写入页面配置。日志位于 `artifacts/launcher/`，界面显示时截断长度并遮蔽凭据。

`profile_labels` 保存显示名称，`profile_create_receipts` 保存创建回执，`profiles.name` 保持内部 ASCII 标识。新档的基础记录、教程进度、显示名称和回执在同一事务中创建；重命名检查原显示名称，避免覆盖其他窗口的修改。

相关测试位于 [console/tests](tests/) 和[启动器接口测试](../tests/test_admin_launcher.py)。按改动范围选择定向用例，不需要每次运行全量测试。
