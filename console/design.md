# 控制台界面设计

控制台采用 Edge 独立应用窗口承载本机 Web 界面（无地址栏）；Python 后端负责读取本机管理凭据、签发一次性票据并拉起窗口，前端完成认证后即刻清除 URL 中的票据参数。

界面配色采用深梅紫导航（`#241D35`）、浅灰紫工作台（`#F5F4F8`）、白色编辑面板（`#FFFFFF`）与深紫/青绿状态色（`#2D253A`、`#7652CC`、`#258572`）。字体优先使用 Microsoft YaHei UI 与 Segoe UI Variable，启用等宽数字特性（tabular-nums）。

整体布局由左侧固定功能栏、顶部存档与连接状态栏、中央可搜索操作列表、右侧表单与变更预览区组成：

```
连接地址       当前存档              客户端同步状态
功能分类 | 搜索、操作和数据目录 | 字段编辑 / 修改预览
         |                    | 预览修改、应用修改
操作结果与生效提示
```

状态色仅用于标识离线、等待、成功与失败状态。切换存档或修改表单输入时自动作废旧预览，防止跨档误提交。`-Demo` 演示模式使用内置合成数据运行，用于界面布局与交互调试。
