# 繁体翻译集成

翻译来自 https://github.com/s88037zz/dotabyss-translation ，插件来自 https://github.com/s88037zz/AbyssMod 。保留原繁体译文，使用完整本地缓存，不依赖游戏运行时访问 CDN。MIT 许可随插件保存为 LICENSE.AbyssMod。

## 启动器一键安装

准备好本地 PC 客户端、Git 和 .NET SDK 后，打开启动器，在“繁体中文”栏点击“一键安装”或“更新翻译”。无需先启动游戏服务。首次使用会获取固定版本的插件源码、兼容补丁及经过哈希校验的字体和依赖，同时获取译文；后续更新使用相同流程。

阶段进度、结果和日志显示在启动器中。安装前需要退出游戏；更新期间启动器会阻止打开游戏。安装完成后，下次启动游戏生效。关闭浏览器窗口不会中断后台任务。

更新会保留无关配置、备份原有翻译。检测到上游仓库有额外本地修改，或本地字典与新译文冲突时，会停止并显示原因。下载的完整译包、缓存和备份保留在本机；本项目维护的通用补译位于 `overrides/`。

## 来源与安装布局

插件源码、译文提交、依赖版本和覆盖统计集中记录在[翻译基线](../changelog.md#翻译基线)。Utility.dll 和字体 ttcuyuanj 从指定上游发布包提取并校验 SHA256。插件以目标 PC 客户端的 BepInEx core 与 interop 编译，不替换 BepInEx、winhttp.dll 或现有私服插件。

实际路径为 `dotabyss_pc/local-client/BepInEx/plugins/AbyssMod/`，配置在同一客户端的 `BepInEx/config/AbyssMod.cfg`。翻译启用、语言为 zh_Hant、CDN 为空；机翻和采集关闭，General 四项为 true 以保留游戏原行为。原始上游清单另存，实际缓存清单由本地文件重新生成。

## 通用文本补译

按目标客户端的主表、教程资源和实际 UI 控件核对，补译包含：

- 被动、觉醒和主动技能说明、技能名称、魔力水晶及深渊代碼效果。
- 教程资源中的文字、训练帮助与过场提示。
- 固定按钮、确认框、菜单和原生提示；数值、角色名等格式化参数保留原值。
- 任务条件、商品说明、礼包内容、订阅说明、兑换分类。
- 设施、研究、酒馆提案、道具用途，以及缺失的角色、服装和武器外观名称。

补译独立于上游 checkout。每次安装会先校验变量、数字、标签和换行，再合并进本地缓存。上游提供有效译文时优先保留上游；`corrections.json` 中的纠错仅在原译文与已核对的 `expected` 完全一致时生效。手动修改过的已安装字典继续受到冲突保护。

`mapping-overrides.json` 补充遗漏的主表字段绑定，不修改游戏主数据、存档、技能数值或玩家输入。新版本出现的新文本需要继续补译，不能靠旧字典自动覆盖。

## 本地兼容处理

排除主表 MNgWords 和字典类型 m_ng_words 的翻译映射，保持名字过滤规则。`input-text-compat.patch` 保护 TMP_InputField 的实际输入值，使文字 setter、OnEnable、周期刷新和直接 UI 翻译都跳过用户输入；输入框占位提示仍可翻译。

`general-text-compat.patch` 修复空旧字典屏蔽新技能字典、格式化技能无法命中，以及纯汉字文本被误判成已翻译的问题。运行时匹配区分技能数值和 UI 参数，保留固定秒数、HIT 数与触发门槛；存在冲突的动态句子保留原文，不按加载顺序猜选。

插件构建项目仅引用当前本地运行环境，不使用上游 csproj 的浮动 NuGet 版本。通用兼容补丁应用到 `artifacts/translation/build-source-*` 构建副本，不影响上游 checkout 的更新检查。纯托管匹配代码在 `runtime/`，定向验证在 `tests/`。

## 更新

退出游戏后，在项目根目录运行：

```powershell
.\update-translation.ps1 -Fetch
```

这会快进更新独立译文仓库，验证并合并通用补译、重新生成本地清单、构建兼容插件，并备份后安装。只重新安装现有内容则省略 `-Fetch`。上游插件源码不会自动升级，升级插件需重新核对兼容补丁。

安装记录与逐文件哈希在 `artifacts/translation/installed.json`，备份位于 `artifacts/translation/backups/`。更新器保留不属于上次安装清单、且不与新译文冲突的本地补充文件。若译文仓库有本地修改，Fetch 会停止以保留修改。

F8 是上游的翻译开关；F10 仅重载配置，不能完整更换已载入字典、语言或字体。安装和更新后重启游戏生效，无需重启私服服务。

## 已知范围

原译包和通用补译不是完整游戏的覆盖保证。使用图片内文字的帮助页需要单独重绘图片；资源中未确认真实用途的占位文本没有强行翻译。缺失译文或动态匹配有歧义时仍显示日文。

上游清单存在过期哈希与缺失的 static 引用，本地按实际文件重建。原译文中少量既有 size 标签问题未作批量改写。

覆盖统计中的原文相同、空值和待重绘图片分别见[翻译基线](../changelog.md#翻译基线)。m_characters 中的重叠名字仍按插件原有 names 优先级处理。

## 验证记录

基础集成曾实机确认字体 TTCuYuanJ SDF、主表翻译和剧情本地缓存正常加载。通用补译另做字典结构、合并升级、动态匹配与插件构建的定向检查；托管 UI 测试不能替代每个页面的原生实机检查。实际安装批次、补译统计和逐文件哈希以 `artifacts/translation/installed.json` 为准。
