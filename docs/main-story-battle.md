# 主线战斗与教程

介绍 PC 客户端的主线章节、剧情播放、重复挑战、扫荡与序章教程逻辑。其他常驻玩法见 [其他常驻战斗模式](other-battle-modes.md)，活动玩法见 [活动与本地复刻](events-and-reruns.md)。

## 支持流程

- **主线剧情**：章节进入、战前剧情播放/跳过、战斗结算、战后与纯剧情节点、整关通关、下一章解锁、中途退出续接及剧情回看。
- **主线战斗**：支持地下城与防卫战场、首通奖励、末尾剧情、整关奖励与下一关开放。
- **会话保持**：开战重试或重启服务后自动恢复同一场战斗会话；失败、放弃或取消会话不推进章节进度。
- **周回与扫荡**：区域通关后开放重复挑战与扫荡（单次 1–100 场，按主表体力×次数扣除并复用结算逻辑）。
- **序章教程**：新档按原生 `0 → … → 13 → 99` 状态推进，两场教程战使用固定编队（`party_no=0`）且不消耗体力。
- **任务统计联动**：通关、消耗体力、击杀总数与指定敌人种类（按 `m_job_id`）自动同步至任务进度。

战斗演出与伤害计算由客户端本地执行，服务端负责战场生成、实体与击杀校验、掉落抽取及事务结算。

## 可配置本地规则

可在数据目录的 `gameplay-rules.json` 中自定义主线掉落与战场参数（修改后对新开战局生效）：

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `battle_drop_probability_per_mille` | 300 | 每个敌人或资源点产出公开掉落的概率（千分比，`0` 为关闭） |
| `battle_rare_drop_probability_per_mille` | 50 | 普通池与稀有池并存时命中稀有池的概率（千分比） |
| `battle_player_exp_per_stamina` | 1 | 胜利时每消耗 1 点体力获得的玩家经验 |
| `battle_first_reward_group_mode` | 2 | 首通奖励组模式（`0` 关闭；`1` 区域基数；`2` 区域基数+任务顺序偏移） |
| `battle_dungeon_lottery_weighted` | 1 | 地下城敌群抽取方式（`1` 按权重抽取；`0` 均匀抽取） |
| `battle_defence_enemy_copies` | 1 | 防卫关每条公开敌人记录生成的普通敌人数 |
| `battle_defence_enemy_energy` | 300 | 防卫关普通敌人掉落的能量值 |

额外掉落基于主表 `addition_extra_drop_probability`，叠加已生效的研究、VIP 与订阅加成（上限 1000‰）。
