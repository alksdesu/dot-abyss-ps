# 活动与本地复刻

支持全部 9 类常驻/限时活动玩法、奖励关及遭遇活动，默认开放主表中的所有活动配置。活动数量统计见 [内容快照](../changelog.md#内容快照)。

[返回文档目录](README.md)

## 已接入活动类型

| 类型 | 支持流程 |
| --- | --- |
| 采矿 (`Miner`) | 矿车推进、成败分支、C/B/A/S 评级、次数恢复、首通与周回奖励、扫荡 |
| 凶化厄灾 (`Mutant`) | Boss 跨场持续血量与阶段、出战角色限制、设施编队与燃料、重置、扫荡、个人榜与排名奖励邮件 |
| 剧情活动 (`Story`) | 剧情前置、普通关与挑战关、首通与周回奖励、关卡扫荡、剧情回想 |
| 寻宝棋盘 (`TreasureBoard`) | 消耗活动币开格、大奖推进、最终棋盘无限循环 |
| 狩猎 (`Hunt`) | 体力关、首领券掉落、首领关、活动专属增益升级与开关、后日谈解锁 |
| 箱池 (`BoxGacha`) | 限量奖池抽取、累计/增量结算、大奖重置、最终箱循环 |
| 委托 (`Commission`) | 前置解锁、关卡奖励、最快通关时间与最高 FC 伤害任务、编队支援加成 |
| 养成 (`Training`) | 活动剧情、每日挑战次数、关卡推进、固定编队试玩 |
| 竞速 (`SpeedRun`) | 分组解锁、单关/整组最快时间记录、稀有度及纹章限制任务 |

此外完整支持活动奖励关（触发、放弃、挑战、首通、扫荡）与遭遇活动（`encount_type=10/11`）。

## 活动开放、切换与实例重置

- **全活动开放控制**：`gameplay-rules.json` 中默认设置 `event_open_all=1`（开放主表全部活动）；设为 `0` 时可通过 `event_open_ids` 指定开放列表。服务端自动生成派生主表视图（缓存在 `master/event-views/`），同步延长关联卡池、任务、商店兑换与代币的有效期。
- **切换遭遇活动**：由于客户端原生界面每次仅展示一期遭遇活动，可在控制台通过“选择遭遇活动”实时切换当前生效的期数。
- **主线前置条件**：普通活动需通关主线 1-1，委托活动需通关第 3 章，凶化厄灾需通关第 6 章。
- **重置活动与箱池**：控制台提供“重置整个活动实例”（清空指定活动的进度、任务、剧情与兑换记录，以便重新游玩拿奖）和“重建指定活动箱池”功能。

## 活动币产出与加成

- **货币类型**：活动币为 `content_type=54`，首领券为 `56`，全局时限资源为 `120`，抽卡代币为 `170`。
- **主线联动产出**：通关主线、常驻外传与活动体力关均可产出当前已参加活动的体力币（按 `ceil(体力 × boost_rate / 1000 / stamina_base)` 计算），并按概率触发活动奖励关。
- **特效角色加成**：按出战或上次通关阵容自动匹配特效角色的掉落加成倍率。

## 可配置本地规则

可在 `gameplay-rules.json` 中调整以下活动参数：

- **采矿与凶化厄灾恢复**：采矿单局默认 60 秒（`event_miner_battle_seconds`），每日免费补给 3 次；采矿与凶化厄灾默认每日可购买 3 次挑战次数、每次消耗 50 钻石（`event_miner_recovery_*` / `event_mutant_recovery_*`）。
- **凶化厄灾排名奖励**：`event_mutant_ranking_reward_on_query=1` 时，打出有效成绩后查询榜单即自动通过邮件发放一次个人排名奖励（设为 `0` 关闭）。
- **特效角色加成倍率**：`event_bonus_character_rate_scale` 默认为 `1000`（100% 应用主表角色加成，设为 `0` 关闭）。
